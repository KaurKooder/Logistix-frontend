# Projekti seadistamise juhend

## Gradle
Kohe kui projekt on intellij-s, siis peaks alla paremasse nurka ilmuma build gradle - see tuleb alla laadida.

## Node js
Kõigepealt vaata kas sul on node.js arvutisse installitud:
* ava cmd või windows powershell
* sisesta commandid: node -v, npm -v
* kui ei leia üles, siis ava lehekülg: https://nodejs.org/ - ja sealt installi node.js
* tee intellij-s restart
* ava intellij-s terminal ja sisesta command: npm install
* vaata kas backend poolel application käib
* sisesta command: npm run dev ja siis peaks tulema localhost link
